发布说明

这是纯静态站点，适合直接放进 GitHub Pages 的发布目录。

推荐发布方式

  1. 把本文件夹内所有文件放到 GitHub Pages 仓库根目录，或放到仓库的 docs/ 目录。
  2. 在 GitHub 仓库的 Settings / Pages 中选择对应分支与目录。
  3. 发布后访问 https://用户名.github.io/仓库名/。

当前文件清单

index.html 是入口页；三个 步步_*.html 是原型页；.nojekyll 用于让 GitHub Pages 按静态文件原样发布。
